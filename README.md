# Luma Shell

Luma добавляет в Windows 11 плавающий Dock, верхнее меню и Dynamic Island в духе macOS. Панели отображаются на основном мониторе, скрываются в полноэкранном режиме и исключены из Alt+Tab.

## Установка

Скачайте `LumaShell-win-x64.exe` для Intel и AMD или `LumaShell-win-arm64.exe` для Windows на ARM. Закройте предыдущую версию через меню Luma, перенесите новый `.exe` в папку, где у вас есть право записи, и запустите его. Сборки переносимые, со встроенным .NET и без цифровой подписи. [Скачать последнюю версию](https://github.com/dT0lkien/LumaShell/releases/latest)

Luma по умолчанию скрывает панель задач Windows, пока включено её оформление. Исходное состояние восстанавливается при выходе. Отдельный процесс восстанавливает панель после аварийного завершения Luma. Настройка **Вид → Вернуть панель задач Windows** позволяет отключить скрытие. Команда **Временно показать панель Windows** в меню Luma или `Ctrl+Alt+B` возвращает доступ к оригинальному трею.

## Панели и остров

- **Dock.** Крупные векторные значки встроенных функций, собственные значки приложений без дополнительных рамок, стеклянная подложка, «Загрузки» и корзина. При запуске значок подпрыгивает, а точки открытых приложений остаются на одной линии. Соседние иконки плавно увеличиваются и раздвигаются под курсором вместе с точками и разделителями. Стеклянная подложка расширяется на время анимации. Точки показывают открытые окна, щелчок переключает окно, правый щелчок показывает список окон. Свой `.exe` можно перетащить на Dock или добавить через **Dock → Закрепить приложение…**.
- **Меню приложений.** Одиночное нажатие `Win` или кнопка **Приложения** в Dock открывает поиск по установленным приложениям. `Enter` запускает выбранное, `Esc` закрывает меню. Сочетания с `Win` сохраняются. Назначение клавиши можно вернуть в меню Luma слева вверху.
- **Пункт управления.** Верхняя строка показывает активное приложение, время, сеть и заряд. Кнопка с ползунками открывает громкость системного выхода, отключение звука, ссылки на питание и сеть, события и обновления.
- **Трей приложений.** Стрелка в верхней строке открывает список приложений. Если живой список Explorer неполный, Luma добавляет значки зарегистрированных в Windows приложений, которые сейчас запущены. Левый клик вызывает основное действие самого значка Explorer через UI Automation, правый — родное меню приложения. Для классических меню Luma задаёт положение слева от списка. Скрытый overflow Explorer подготавливается отдельно от панели задач. Значок сопоставляется по GUID/UID и координатам, а при отсутствии идентификатора — по уникальной подписи. Если Windows не предоставляет действие, левый клик пытается переключить уже открытое окно, а правый показывает действия Luma слева; оригинальный системный трей доступен по `Ctrl+Alt+B`. Некоторые приложения открываются только по двойному щелчку в родном трее и могут иначе трактовать стандартное действие доступности.
- **Снимки.** `Win+Shift+S` с включённым режимом Luma сохраняет выбранную область или весь монитор под курсором прямо в PNG. На новых установках режим включён по умолчанию. Настройка и папка доступны на вкладке **Снимки**. `Ctrl+Alt+S` и кнопка **Сделать снимок** также запускают захват.
- **События.** После разрешения Windows Luma показывает до 15 событий из центра уведомлений. Доступ зависит от конфигурации Windows. Записи хранятся в памяти и очищаются при отключении.
- **Prism VPN.** Luma проверяет локальный API на loopback и сопоставляет процесс `sing-box.exe` с установленным Prism. При доступном API показывается выбранный узел. Для нестандартного расположения профиля укажите папку через шестерёнку рядом с Prism. Ключ API читается локально и используется только для запроса к loopback.
- **Внешний IP.** В капсуле отображается флаг страны, а на вкладке **Главная** можно скопировать адрес и обновить его вручную. Адрес и страна определяются по HTTPS-запросу к Cloudflare примерно раз в минуту и при изменении статуса Prism. Результат отражает маршрут этого запроса. Флаги из [flag-icons 7.5.0](https://github.com/lipis/flag-icons) встроены в приложение по [лицензии MIT](assets/flags-LICENSE.txt).
- **Zapret.** Если в Prism установлена служба Windows, остров показывает её состояние и позволяет включить или выключить её с подтверждением Windows. Luma проверяет путь к `winws.exe` службы. Если zapret запускается внутри Prism, откройте Prism из карточки для управления или установки службы.
- **Музыка, буфер и фокус.** Остров управляет системной медиасессией, хранит до десяти текстовых копирований в памяти при включённой истории и показывает таймер фокуса. Открыть остров можно наведением или `Ctrl+Alt+Пробел`.

Обои `Luma-Wallpaper.png` доступны в релизах. Их можно применить в **Параметры → Персонализация → Фон**.

## Автообновление

Начиная с 0.3.0 Luma проверяет стабильный GitHub Release вскоре после запуска и затем примерно раз в шесть часов. Она скачивает `.exe` для своей архитектуры, сверяет SHA-256 из метаданных GitHub и устанавливает обновление при обычном выходе. **Пункт управления → Проверить обновления** запускает проверку сразу. После загрузки там же можно установить обновление с перезапуском. Обновление заменяет текущий `.exe` в его папке и оставляет предыдущую версию рядом с расширением `.previous`.

## Сборка и выпуск

Требуется .NET 10 SDK. Для ARM64 замените `win-x64` на `win-arm64` в аргументах `-r` и `-o`.

```powershell
dotnet publish src/LumaShell.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=None -o artifacts/win-x64
```

Чтобы выпустить обновление, измените `<Version>` в `src/LumaShell.csproj`, создайте тег с той же версией в формате `vX.Y.Z` и отправьте его в GitHub. Workflow собирает обе архитектуры и публикует стабильный релиз.

Референс для поведения острова — [Island](https://github.com/exuupery/island). События читаются через [Windows UserNotificationListener](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/app-notifications/notification-listener).

Для родных меню значков используется [UI Automation COM Interop](https://github.com/Roemer/UIAutomation-Interop) по [лицензии MIT](assets/uia-LICENSE.txt).
